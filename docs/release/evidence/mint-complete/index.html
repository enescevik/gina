GINA — onaylı mint tasarımı

1 Kasım 2026. Bu sayfa yeni tasarım maketi değil, uygulamadan alınan ekran görüntüleridir. Native grubu iPhone 17 Pro / iOS 26.5 simülatöründendir; diğerleri telefon/tablet ölçülerinde web uygulamasıdır. Tüm görüntüler izole test verisi kullanır; gerçek aile kayıtları değiştirilmedi.

Oda onaylı özgün kaynakla sabittir. Saat/hava değişimi ve bağımsız maskot animasyonu bu teslimde yoktur. Simülatördeki gri dişli, geliştirme aracının düğmesidir; TestFlight arayüzünün parçası değildir.
